## 地區及資料檢查

要求來源 complete_address.country 為 HK，且座標介乎緯度 22.15–22.57、經度 113.8–114.45。這是粗略座標範圍加來源地區標記，不是香港邊界多邊形檢查，也不是逐店地址核實。42 筆境外資料包括日本、台灣、深圳的搜尋結果。

非餐廳及類型不明項目包含商場、按摩店、雜貨店及欠分類資料；只因沒有可靠分類而排除的項目不等於確認不是餐廳。一般 Restaurant、Cafe、Buffet 等保留為未分類；不依查詢字眼或店名猜菜式。現在只對照主要 category，不自動擴展含糊的次要類別。

CLOSED 等明確狀態才標為停業；Brunch、Dogs allowed 及描述文字均視為營業狀態未知。營業時間目前仍顯示未知。無評分的記錄不顯示為零星。保留 Google Maps 餐廳資料頁連結；不打包評論、評論者資料、電話及電郵。
