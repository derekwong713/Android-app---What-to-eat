# App documentation website

Buildless, responsive Traditional Chinese documentation. Open index.html locally, or configure GitHub repository Settings → Pages → Deploy from a branch → main → /docs. No hosting change is made by adding these files. Pages availability depends on repository visibility/account settings.

No external fonts, scripts, analytics or API keys. Content reflects the bundled, account-free product; the catalogue is currently empty. This is app documentation, not a finalized legal privacy policy.
